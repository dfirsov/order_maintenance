# Source papers

The papers this work builds on. They are not redistributed here; see the publishers or the links.

* Paul F. Dietz and Daniel D. Sleator. *Two algorithms for maintaining order in a list.*
  STOC 1987, pp. 365–372. Full version: Carnegie Mellon University technical report CMU-CS-88-113, 1988.
* Michael A. Bender, Richard Cole, Erik D. Demaine, Martin Farach-Colton and Jack Zito.
  *Two simplified algorithms for maintaining order in a list.* ESA 2002, LNCS 2461, pp. 152–164.
* Tsvi Kopelowitz. *On-line indexing for general alphabets via predecessor queries on subsets of an
  ordered list.* FOCS 2012. arXiv:1208.3798, <https://arxiv.org/abs/1208.3798>.
* Gerth Stølting Brodal. *List order maintenance.* Lecture slides, Advanced Algorithms, Aarhus
  University, 2013.

Local copies, if any, are kept out of version control (`.gitignore`).
